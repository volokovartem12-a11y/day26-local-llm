# День 26. Запуск локальной LLM

Локальная модель через **Ollama**: запуск на своём компьютере, обращение через
**CLI** и **HTTP API**, 4 запроса возрастающей сложности с автоматической проверкой
ответов. Ключи и интернет-API не нужны — интернет только для скачивания модели.

## Что выбрано и почему

| | |
|---|---|
| **Ollama** | проще всего на Windows: одна установка, CLI-команды и HTTP API на `localhost:11434` |
| **Qwen 2.5 7B** (`qwen2.5:7b`) | хорошо понимает русский, пишет код, ≈ 4.7 ГБ. Поменьше и быстрее на процессоре — `qwen2.5:3b` |

## GPU или процессор — важная оговорка

Видеокарта AMD Radeon RX 9060 XT — новое поколение RDNA 4. Официальный Ollama для
Windows поддерживает её не «из коробки»: у части пользователей Ollama её не видит и
молча работает на процессоре. GPU-ускорение для этих карт сейчас получают обходными
путями — сборкой с ROCm 7 HIP SDK или через WSL.

Для задания это не мешает: при 96 ГБ RAM модель 7B работает и на процессоре, только
медленнее. Скрипт **сам показывает**, где реально работает модель (`ollama ps`,
колонка PROCESSOR, и строка «модель работает на: …»), и скорость в токенах в секунду.

## Запросы (`tests.json`)

| # | Сложность | Запрос | Как проверяется |
|---|---|---|---|
| 1 | простой | столица Франции одним словом | в ответе «Париж» |
| 2 | средний | сколько замен масла за 8 часов на 3 подъёмниках по 40 мин | в ответе «Ответ: 36» |
| 3 | сложный | функция `is_palindrome` на Python | код **извлекается и запускается** на 5 тестах (русский, английский, пустая строка) |
| 4 | сложный | извлечь из сообщения клиента имя, телефон, машину, услугу в JSON | ответ разбирается как JSON, сверяется каждое поле |

Код модели запускается в отдельном процессе во временной папке с ограничением 10 секунд;
код с опасными операциями (`os`, `subprocess`, `open(` …) не запускается.
Рассуждения в тегах `<think>…</think>` (у Qwen3, DeepSeek-R1) из ответа вырезаются.

## Файлы

| Файл | Роль |
|---|---|
| `local_llm.py` | клиент HTTP API Ollama на стандартной библиотеке Python: проверка сервера, модели, запросы, проверки, отчёт |
| `tests.json` | 4 запроса с правилами проверки |
| `run.ps1` | всё по шагам: Ollama → сервер → модель → запрос через CLI → запросы через HTTP API |

## Запуск (PowerShell)

```powershell
winget install Ollama.Ollama          # один раз; затем переоткрыть PowerShell
cd "путь\до\day26-local-llm"
.\run.ps1                             # проверка целиком
.\run.ps1 -Mode chat                  # диалог в CLI Ollama
.\run.ps1 -Mode ask -Query "Что такое RAG?"
```

Через HTTP API можно обратиться и без скрипта:

```powershell
Invoke-RestMethod http://localhost:11434/api/generate -Method Post -ContentType "application/json" `
  -Body '{"model":"qwen2.5:7b","prompt":"Привет! Кто ты?","stream":false}' | Select-Object -ExpandProperty response
```

Результат — `output/local_llm_report.md`: таблица запросов, проверки, время, скорость и ответы.
